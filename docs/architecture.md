# YiCode 系统架构

## 整体架构

YiCode 采用前后端分离的架构，主要包含以下几个部分：

### 1. 桌面应用 (Tauri + React)
- 使用 Tauri 框架构建跨平台桌面应用
- React + TypeScript 实现用户界面
- Monaco Editor 提供代码编辑功能
- 通过 WebSocket 与后端实时通信

### 2. 本地API服务 (FastAPI)
- 提供 RESTful API 接口
- 管理本地项目和文件
- 处理代码执行请求
- 用户认证和权限管理

### 3. 课堂管理服务
- 管理教室、学生、教师信息
- 实时课堂互动功能
- 作业提交和批改系统
- 广播和通知功能

### 4. 运行时管理
- Python 环境检测和管理
- 虚拟环境创建和管理
- 包管理和依赖解析
- 代码执行沙箱

### 5. AI Provider 集成
- 支持多种AI模型（OpenAI等）
- 代码补全和提示功能
- 智能错误诊断
- 学习建议和辅导

## 数据流

`
用户界面 (React)
    ↓ HTTP/WebSocket
本地API服务 (FastAPI)
    ↓
SQLite 数据库
    ↓
运行时管理器
    ↓
Python 执行环境
`

## 技术选型理由

### Tauri
- 跨平台支持（Windows, macOS, Linux）
- 轻量级，性能好
- 原生系统集成能力

### FastAPI
- 现代Python Web框架
- 自动生成API文档
- 异步支持，性能优秀
- 类型提示，开发体验好

### SQLite
- 无需额外数据库服务
- 单文件存储，便于部署
- 足够满足本地应用需求

### WebSocket
- 实时双向通信
- 低延迟，适合协作场景
- 浏览器原生支持

## 安全考虑

1. **代码执行沙箱**: 限制代码执行权限，防止恶意操作
2. **本地数据加密**: 敏感数据本地加密存储
3. **API 认证**: JWT token 认证机制
4. **输入验证**: 严格的输入验证和过滤
5. **错误处理**: 统一的错误处理和日志记录

## 扩展性设计

1. **插件系统**: 支持功能插件扩展
2. **主题定制**: 支持界面主题定制
3. **多语言支持**: 国际化支持
4. **云同步**: 可选的数据云同步功能
